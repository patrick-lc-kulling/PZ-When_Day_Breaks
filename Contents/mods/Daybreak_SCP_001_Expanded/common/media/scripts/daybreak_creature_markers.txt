       their own models. Each is the vanilla hard hat pinned to one colour, so
       a type can be told apart at a glance:
           Conjoined = yellow, Caller = white, Grasper = red, Mass = blue.

       They drop on the corpse like any outfit clothing, so they are made
       worthless on purpose: no bite or scratch defense, and the plain hat
       slot, which the sun code does not count as covering the head at all.
       Anything better would turn every evolved kill into free protective
       gear. ChanceToFall 0 keeps the marker on while the creature is hit. */

    item Daybreak_Marker_Conjoined
    {
        DisplayCategory = Accessory,
        ItemType = base:clothing,
        Weight = 0.5,
        Icon = HardHatYellow,
        BodyLocation = base:hat,
